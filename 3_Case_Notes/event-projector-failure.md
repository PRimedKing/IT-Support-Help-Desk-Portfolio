# Case: Projector loses signal 20 minutes before event start

**Date:** 2025
**Environment:** University conference venue, Windows laptop feeding a ceiling projector over HDMI, 200+ attendees arriving
**Reported by:** event coordinator (no names)

## Problem
Projector showed "no signal" with the keynote starting in 20 minutes.

## What I asked and checked
1. What changed? The laptop had been swapped for the speaker's own machine five minutes earlier.
2. Cable first: reseated the HDMI at both ends — no signal.
3. Input source: the projector was still set to the input the old laptop used. The new laptop was on a different port.
4. Display output: confirmed the laptop was actually sending video (Win+P set to duplicate, external display detected in settings).

## Cause
Two small things at once: the projector was on the wrong input, and the replacement HDMI run was loose at the wall plate.

## Fix
1. Switched the projector to the correct input.
2. Reseated the wall-plate connection and confirmed it clicked in.
3. Ran the first three slides to confirm video and audio.
4. Kept my own laptop warmed up backstage as a backup source for the rest of the event.

## Result
Signal restored with about 12 minutes to spare. Keynote started on time.

## What I'd do differently or document
I now keep a pre-event checklist: confirm input source, test with the actual presenting laptop (not mine), and always have a backup machine ready. The fix took two minutes — the panic took the other eighteen.
